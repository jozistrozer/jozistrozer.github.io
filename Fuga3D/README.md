# Fuga3D

Open https://jozistrozer.github.io/Fuga3D/

Visual room drawing, per-axis cut placement, reference-wall alignment and interactive laying sequence. Projects and cut preferences are saved locally in your browser; export JSON for backups. Sequence playback is session-only.

Validated: 50 tests, TypeScript, production build and browser checks of room drawing, wall dragging, undo/redo, cut placement and laying steps.
